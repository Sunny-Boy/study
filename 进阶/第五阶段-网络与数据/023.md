# 023. SharedPreferences 持久化与类型安全封装

`SharedPreferences` 是 Flutter 中最易上手的轻量级持久化方案，适合存储体积小、结构简单的键值对数据（如配置项、开关状态、最近一次登录信息等）。

## SharedPreferences 的核心特性

- **存储介质**：底层分别依赖 iOS 的 `NSUserDefaults` 与 Android 的 `SharedPreferences`。
- **数据类型**：支持 `int`、`double`、`bool`、`String`、`List<String>` 五类基础类型。
- **异步初始化**：通过 `SharedPreferences.getInstance()` 获取全局单例。
- **场景定位**：适合保存配置与状态，而非大体量数据或结构复杂的对象。

## 基础用法

```dart
import 'package:shared_preferences/shared_preferences.dart';

class PrefsManager {
  PrefsManager._();
  static final PrefsManager instance = PrefsManager._();

  SharedPreferences? _prefs;

  Future<void> init() async {
    _prefs ??= await SharedPreferences.getInstance();
  }

  Future<void> setOnboardingFinished(bool value) async {
    await _prefs?.setBool('onboarding_finished', value);
  }

  bool get onboardingFinished => _prefs?.getBool('onboarding_finished') ?? false;
}
```

- 在应用启动（如 `main()`）阶段初始化：`await PrefsManager.instance.init();`
- 注意区分 `set` 系列方法的返回值：写入成功返回 `true`，可根据结果提示用户。

## 构建类型安全的封装

直接使用字符串 Key 易出现拼写错误或类型不一致。可以通过枚举与泛型封装一个安全层：

```dart
enum PreferenceKey<T> {
  onboardingFinished<bool>('onboarding_finished'),
  themeMode<String>('theme_mode'),
  favoriteTags<List<String>>('favorite_tags');

  const PreferenceKey(this.key);
  final String key;
}

class TypedPreferences {
  TypedPreferences(this._prefs);

  final SharedPreferences _prefs;

  T getValue<T>(PreferenceKey<T> key, T defaultValue) {
    final value = _prefs.get(key.key);
    if (value is T) {
      return value;
    }
    return defaultValue;
  }

  Future<bool> setValue<T>(PreferenceKey<T> key, T value) {
    switch (value) {
      case bool():
        return _prefs.setBool(key.key, value as bool);
      case int():
        return _prefs.setInt(key.key, value as int);
      case double():
        return _prefs.setDouble(key.key, value as double);
      case String():
        return _prefs.setString(key.key, value as String);
      case List<String>():
        return _prefs.setStringList(key.key, value as List<String>);
      default:
        throw UnsupportedError('Unsupported type ${value.runtimeType}');
    }
  }
}
```

- `PreferenceKey` 统一管理 Key 名称与类型约束。
- `TypedPreferences` 使用模式匹配（requires Dart 3）判断类型，并调用对应的 `set*` 方法。
- 可进一步封装读写通知，结合 `ChangeNotifier` 或 `ValueNotifier` 实现状态同步。

## 设置向导（Wizard）示例

在首次启动时，可通过设置向导引导用户完成偏好配置，并即时保存：

```dart
class SetupWizardController extends ChangeNotifier {
  SetupWizardController(this._prefs);

  final TypedPreferences _prefs;
  int _step = 0;
  String _theme = 'system';
  List<String> _topics = const [];

  int get step => _step;
  String get theme => _theme;
  List<String> get topics => _topics;

  void next() {
    if (_step < 2) {
      _step += 1;
      notifyListeners();
    }
  }

  void previous() {
    if (_step > 0) {
      _step -= 1;
      notifyListeners();
    }
  }

  void selectTheme(String value) {
    _theme = value;
    _prefs.setValue(PreferenceKey.themeMode, value);
    notifyListeners();
  }

  void updateTopics(List<String> value) {
    _topics = value;
    _prefs.setValue(PreferenceKey.favoriteTags, value);
    notifyListeners();
  }

  Future<void> complete() async {
    await _prefs.setValue(PreferenceKey.onboardingFinished, true);
  }
}
```

在界面层可使用 `Stepper`/`PageView` 等组件：

```dart
class SetupWizardPage extends StatelessWidget {
  const SetupWizardPage({super.key, required this.controller});
  final SetupWizardController controller;

  @override
  Widget build(BuildContext context) {
    return AnimatedBuilder(
      animation: controller,
      builder: (context, _) {
        return Stepper(
          currentStep: controller.step,
          onStepContinue: controller.next,
          onStepCancel: controller.previous,
          steps: [
            Step(
              title: const Text('主题模式'),
              content: Column(
                children: [
                  RadioListTile(
                    title: const Text('跟随系统'),
                    value: 'system',
                    groupValue: controller.theme,
                    onChanged: (value) => controller.selectTheme(value!),
                  ),
                  RadioListTile(
                    title: const Text('黑暗模式'),
                    value: 'dark',
                    groupValue: controller.theme,
                    onChanged: (value) => controller.selectTheme(value!),
                  ),
                ],
              ),
            ),
            Step(
              title: const Text('偏好主题'),
              content: Wrap(
                children: ['Flutter', 'Dart', '后端', 'AI']
                    .map((topic) => FilterChip(
                          label: Text(topic),
                          selected: controller.topics.contains(topic),
                          onSelected: (selected) {
                            final next = [...controller.topics];
                            selected ? next.add(topic) : next.remove(topic);
                            controller.updateTopics(next);
                          },
                        ))
                    .toList(),
              ),
            ),
            Step(
              title: const Text('完成'),
              content: ElevatedButton(
                onPressed: () async {
                  await controller.complete();
                  if (context.mounted) Navigator.of(context).pop(true);
                },
                child: const Text('立即开始'),
              ),
            ),
          ],
        );
      },
    );
  }
}
```

- 向导每一步都即时写入偏好数据，保证中途退出也能保留配置。
- 完成后可设置标记位（如 `onboarding_finished`），下次启动直接跳过。
- 若需加密敏感信息，建议选用 `flutter_secure_storage` 或自建本地数据库。

## 最佳实践总结

1. 将 SharedPreferences 封装成独立服务，避免在业务代码中散落字符串 Key。
2. 配合 `ValueListenableBuilder`、`Riverpod` 等状态管理工具，实现偏好变更的即时刷新。
3. 对需要多人协作的项目，统一维护 Key 与默认值的文档或枚举，避免冲突。
4. 限制存储内容的大小和数量，必要时迁移到 SQLite/Hive 等更适合的数据库方案。
