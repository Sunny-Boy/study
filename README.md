# Flutter 学习知识库（中文）

本仓库旨在构建一套系统化、可循序渐进学习的 Flutter 中文知识库，覆盖从环境搭建、Dart 基础，到组件、状态、路由、网络、性能优化与工程化实践，最后以综合项目实战收尾。

- 入门导航与目录索引请查看：[`000.md`](000.md)
- 仓库中文件按照阶段分类，适合自学与团队内部培训使用。

## 学习目标

- 建立完整的 Flutter 知识体系，理解从基础到实战的能力路径
- 掌握常用组件、状态管理、路由导航与网络数据处理
- 了解工程化与性能优化思路，具备完成中小型项目的能力

## 目录使用方式

- 按 `000.md` 中的阶段顺序学习，逐步阅读各目录下的编号文档（001.md、002.md…）
- 若只需查阅某一块知识点，可直接进入对应阶段目录搜索编号条目
- 每一篇文档包含：知识点讲解、底层原理、大白话解释、实战案例代码 等部分

## 仓库结构（阶段目录）

- 进阶/第三阶段-交互与状态
- 进阶/第四阶段-导航与路由
- 进阶/第五阶段-网络与数据
