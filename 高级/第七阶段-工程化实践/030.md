# 030 - Flutter包管理与依赖配置

## pubspec.yaml详解

### 基础结构
```yaml
name: my_flutter_app
description: A new Flutter project.
publish_to: 'none' # 防止意外发布到pub.dev

version: 1.0.0+1

environment:
  sdk: ">=3.0.0 <4.0.0"
  flutter: ">=3.10.0"

dependencies:
  flutter:
    sdk: flutter
  cupertino_icons: ^1.0.2
  
dev_dependencies:
  flutter_test:
    sdk: flutter
  flutter_lints: ^2.0.0

flutter:
  uses-material-design: true
  assets:
    - images/
  fonts:
    - family: Schyler
      fonts:
        - asset: fonts/Schyler-Regular.ttf
        - asset: fonts/Schyler-Italic.ttf
          style: italic
```

### 版本约束语法
```yaml
dependencies:
  # 精确版本
  package_a: 1.2.3
  
  # 兼容版本 (^1.2.3 等同于 >=1.2.3 <2.0.0)
  package_b: ^1.2.3
  
  # 范围版本
  package_c: ">=1.2.3 <2.0.0"
  
  # 任意版本
  package_d: any
  
  # Git依赖
  package_e:
    git:
      url: https://github.com/user/repo.git
      ref: develop
      path: packages/package_e
  
  # 本地路径依赖
  package_f:
    path: ../local_packages/package_f
```

## 依赖版本管理策略

### 1. 语义化版本控制
```
主版本号.次版本号.修订号 (MAJOR.MINOR.PATCH)

- MAJOR: 不兼容的API修改
- MINOR: 向下兼容的功能性新增
- PATCH: 向下兼容的问题修正
```

### 2. 依赖更新策略
```bash
# 查看过期依赖
flutter pub outdated

# 获取依赖
flutter pub get

# 更新依赖
flutter pub upgrade

# 更新特定包
flutter pub upgrade package_name

# 清理缓存
flutter pub cache clean
```

### 3. 锁定文件管理
```yaml
# pubspec.lock 文件作用：
# - 锁定确切的依赖版本
# - 确保团队环境一致性
# - 应该提交到版本控制

# .gitignore 中不应包含 pubspec.lock
```

## 私有包管理策略

### 1. Git私有仓库
```yaml
dependencies:
  my_private_package:
    git:
      url: https://github.com/mycompany/private_package.git
      ref: v1.2.3
      
  # 使用SSH密钥
  secure_package:
    git:
      url: git@github.com:mycompany/secure_package.git
      ref: main
```

### 2. 本地包开发
```yaml
# 项目结构
my_flutter_project/
├── pubspec.yaml
├── lib/
└── packages/
    ├── shared_models/
    │   ├── pubspec.yaml
    │   └── lib/
    └── common_utils/
        ├── pubspec.yaml
        └── lib/

# 主项目pubspec.yaml
dependencies:
  shared_models:
    path: packages/shared_models
  common_utils:
    path: packages/common_utils
```

```yaml

```

## 常见问题与解决

### 1. 版本冲突
```bash
# 问题：依赖版本冲突
Because myapp depends on package_a >=1.0.0 and package_b ^2.0.0, version solving failed.

# 解决方案
flutter pub deps # 查看依赖树
flutter pub upgrade --major-versions # 允许主版本升级
```

### 2. 缓存问题
```bash
# 清理所有缓存
flutter clean
flutter pub cache clean
flutter pub get

# 重置pub缓存
rm -rf ~/.pub-cache
flutter pub get
```

### 3. 网络问题
```bash
# 配置镜像源
export PUB_HOSTED_URL=https://pub.flutter-io.cn
export FLUTTER_STORAGE_BASE_URL=https://storage.flutter-io.cn

# 或在pubspec.yaml中配置
publish_to: https://pub.flutter-io.cn
```
