# 007. Flutter 工程目录与运行流程

## 学习目标

- 掌握 Flutter 项目的标准目录结构

## 1. Flutter 工程目录结构

### 1.1 创建新项目

```bash
flutter create my_flutter_app
cd my_flutter_app
```

### 1.2 目录结构详解

```
my_flutter_app/
├── android/           # Android 原生代码
├── ios/              # iOS 原生代码
├── lib/              # Dart 代码主目录
│   └── main.dart     # 应用入口文件
├── test/             # 测试文件
├── web/              # Web 平台文件
├── pubspec.yaml      # 项目配置文件
├── pubspec.lock      # 依赖锁定文件
└── README.md         # 项目说明
```

#### 核心目录说明

| 目录 | 作用 | 重要程度 |
|------|------|----------|
| `lib/` | Dart 代码存放，包含所有业务逻辑 | ⭐⭐⭐⭐⭐ |
| `pubspec.yaml` | 项目依赖、资源配置 | ⭐⭐⭐⭐⭐ |
| `android/` | Android 平台特定代码 | ⭐⭐⭐ |
| `ios/` | iOS 平台特定代码 | ⭐⭐⭐ |
| `test/` | 单元测试、集成测试 | ⭐⭐⭐ |

## 2. 应用入口与启动流程

### 2.1 main() 函数分析

```dart
// lib/main.dart
import 'package:flutter/material.dart';

void main() {
  // 1. 确保 Flutter 绑定初始化
  WidgetsFlutterBinding.ensureInitialized();
  
  // 2. 启动应用
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'Flutter Demo',
      theme: ThemeData(
        colorScheme: ColorScheme.fromSeed(seedColor: Colors.deepPurple),
        useMaterial3: true,
      ),
      home: const MyHomePage(title: 'Flutter Demo Home Page'),
    );
  }
}
```

### 2.2 runApp() 机制详解

```dart
// runApp() 的内部逻辑简化版本
void runApp(Widget app) {
  // 1. 创建 WidgetsBinding 实例
  WidgetsFlutterBinding.ensureInitialized();
  
  // 2. 将 Widget 附加到根节点
  WidgetsBinding.instance.attachRootWidget(app);
  
  // 3. 触发首次构建
  WidgetsBinding.instance.scheduleWarmUpFrame();
}
```

### 2.3 启动流程时序图

```
用户点击应用图标
        ↓
  main() 函数执行
        ↓
WidgetsFlutterBinding.ensureInitialized()
        ↓
    runApp(MyApp())
        ↓
   创建 Widget 树
        ↓
   创建 Element 树
        ↓
  创建 RenderObject 树
        ↓
     首屏渲染完成
```

## 3. 完整的启动示例

### 3.1 基础计数器应用

```dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'Flutter 启动流程演示',
      theme: ThemeData(
        primarySwatch: Colors.blue,
      ),
      home: const MyHomePage(title: 'Flutter 启动流程'),
    );
  }
}

class MyHomePage extends StatefulWidget {
  const MyHomePage({super.key, required this.title});

  final String title;

  @override
  State<MyHomePage> createState() => _MyHomePageState();
}

class _MyHomePageState extends State<MyHomePage> {
  int _counter = 0;

  void _incrementCounter() {
    setState(() {
      _counter++;
    });
  }

  @override
  Widget build(BuildContext context) {
    print('MyHomePage build() called - Counter: $_counter');
    
    return Scaffold(
      appBar: AppBar(
        backgroundColor: Theme.of(context).colorScheme.inversePrimary,
        title: Text(widget.title),
      ),
      body: Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: <Widget>[
            const Text(
              'You have pushed the button this many times:',
            ),
            Text(
              '$_counter',
              style: Theme.of(context).textTheme.headlineMedium,
            ),
          ],
        ),
      ),
      floatingActionButton: FloatingActionButton(
        onPressed: _incrementCounter,
        tooltip: 'Increment',
        child: const Icon(Icons.add),
      ),
    );
  }
}
```

## 4. 关键概念总结

### 4.1 重要文件

| 文件 | 作用 | 修改频率 |
|------|------|----------|
| `lib/main.dart` | 应用入口，包含 main() 函数 | 中等 |
| `pubspec.yaml` | 依赖管理、资源配置 | 高 |
| `android/app/build.gradle` | Android 构建配置 | 低 |
| `ios/Runner/Info.plist` | iOS 应用信息配置 | 低 |

### 4.2 启动流程关键步骤

1. **main() 执行**: 应用程序的入口点
2. **runApp() 调用**: 启动 Flutter 框架
3. **Widget 树构建**: 创建界面描述
4. **渲染管线启动**: 将 Widget 转换为可视化界面
5. **首屏显示**: 用户看到第一个界面

### 4.3 常见问题

**Q: 为什么要调用 WidgetsFlutterBinding.ensureInitialized()？**
A: 确保 Flutter 框架在 runApp() 之前完成初始化，特别是在异步操作之前。

**Q: main() 函数可以是异步的吗？**
A: 可以，但需要在调用 runApp() 之前完成所有异步初始化。

```dart
void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  
  // 异步初始化操作
  await Firebase.initializeApp();
  
  runApp(const MyApp());
}
```

**Q: 如何在应用启动时执行初始化操作？**
A: 在 main() 函数中或在根 Widget 的构造函数中执行。
