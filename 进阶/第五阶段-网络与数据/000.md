# 第五阶段 · 网络与数据

本阶段聚焦 Flutter 应用在网络通信与本地数据管理方面的核心知识点，帮助你构建稳定、可靠且易维护的数据层。

## 知识点目录

- [021. HTTP 请求流程与库选择](021.md)：梳理 HTTP 请求的工作机制，并比较 `http` 与 `dio` 两大网络请求库的特点与实践。
- [022. JSON 解析与模型序列化](022.md)：掌握模型封装、`json_serializable` 的生成流程，以及序列化的底层原理。
- [023. SharedPreferences 持久化实践](023.md)：理解偏好存储的适用场景，构建类型安全的封装，并实现一个设置向导示例。
- [024. SQLite 本地缓存与事务控制](024.md)：深入 `sqflite` 表结构设计、事务处理，并搭建一个可靠的本地缓存案例。
- [025. 数据分层架构与状态联动](025.md)：总结 Repository 分层、数据同步策略与错误处理，并展示与状态管理融合的实践案例。
