# 028. 自定义绘制与 Canvas、CustomPainter 渲染流程

当内置组件无法满足视觉需求时，可以借助 `CustomPaint` 与 `CustomPainter` 将像素级的控制权掌握在自己手中。本节将解析渲染流程、Canvas API 以及一个自绘图表示例。

## Flutter 渲染流程回顾

1. **Widget 层**：描述配置（configuration），声明 UI 的抽象结构。
2. **Element 层**：维护组件树与状态关系，负责构建和更新 RenderObject。
3. **RenderObject 层**：执行布局（layout）与绘制（paint），与渲染管线直接交互。

`CustomPaint` 会在渲染树中创建 `RenderCustomPaint`，该对象在 `paint` 阶段调用我们提供的 `CustomPainter` 进行自定义绘制。

## Canvas 与绘制上下文

- `Canvas` 封装了 Skia 绘图引擎，提供 `drawRect`、`drawPath`、`drawCircle` 等方法。
- 坐标系以当前绘制区域左上角为原点，向右为 x 轴正方向，向下为 y 轴正方向。
- 借助 `Paint` 可以设置颜色、线宽、渐变、阴影等属性。
- `Canvas` 支持保存/恢复状态（`save` / `restore`）以及矩阵变换（`translate`、`rotate`、`scale`）。

## CustomPainter 生命周期

一个 `CustomPainter` 至少需要实现：

- `void paint(Canvas canvas, Size size)`：执行绘制逻辑，`size` 是当前画布尺寸。
- `bool shouldRepaint(covariant CustomPainter oldDelegate)`：决定当外部属性变化时是否需要重绘。

可选方法：

- `bool shouldRebuildSemantics`：用于语义树更新。
- `SemanticsBuilderCallback semanticsBuilder`：提供可访问性信息。

记得在不再使用时销毁相关的 `Animation` 或资源，避免内存泄漏。

## 示例：自绘折线统计图

以下示例展示如何实现一个带坐标轴、渐变填充和圆点标记的折线图：

```dart
import 'dart:ui' as ui;
import 'package:flutter/material.dart';

class LineChart extends StatelessWidget {
  const LineChart({super.key, required this.points});

  final List<double> points;

  @override
  Widget build(BuildContext context) {
    return CustomPaint(
      size: const Size(double.infinity, 240),
      painter: _LineChartPainter(points: points),
    );
  }
}

class _LineChartPainter extends CustomPainter {
  _LineChartPainter({required this.points});

  final List<double> points;
  final double _padding = 24;

  @override
  void paint(Canvas canvas, Size size) {
    if (points.isEmpty) return;

    final chartWidth = size.width - _padding * 2;
    final chartHeight = size.height - _padding * 2;

    final maxValue = points.reduce((a, b) => a > b ? a : b);
    final minValue = points.reduce((a, b) => a < b ? a : b);
    final valueRange = (maxValue - minValue).clamp(1e-5, double.infinity);

    // 绘制坐标轴
    final axisPaint = Paint()
      ..color = Colors.grey.shade400
      ..strokeWidth = 1.0;
    final origin = Offset(_padding, size.height - _padding);
    canvas.drawLine(origin, Offset(size.width - _padding, size.height - _padding), axisPaint);
    canvas.drawLine(origin, Offset(_padding, _padding), axisPaint);

    // 构建折线路径
    final path = Path();
    for (var i = 0; i < points.length; i++) {
      final dx = _padding + chartWidth * (i / (points.length - 1));
      final dy = _padding + chartHeight * (1 - (points[i] - minValue) / valueRange);
      final point = Offset(dx, dy);
      if (i == 0) {
        path.moveTo(point.dx, point.dy);
      } else {
        path.lineTo(point.dx, point.dy);
      }
    }

    // 渐变填充
    final fillPath = Path.from(path)
      ..lineTo(_padding + chartWidth, size.height - _padding)
      ..lineTo(_padding, size.height - _padding)
      ..close();
    final gradient = ui.Gradient.linear(
      Offset(_padding, _padding),
      Offset(_padding, size.height - _padding),
      [Colors.blue.withOpacity(0.25), Colors.transparent],
    );
    canvas.drawPath(
      fillPath,
      Paint()
        ..shader = gradient
        ..style = PaintingStyle.fill,
    );

    // 绘制折线
    canvas.drawPath(
      path,
      Paint()
        ..color = Colors.blue
        ..strokeWidth = 3
        ..style = PaintingStyle.stroke
        ..strokeCap = StrokeCap.round,
    );

    // 圆点标记
    final dotPaint = Paint()
      ..color = Colors.blue
      ..style = PaintingStyle.fill;
    for (var i = 0; i < points.length; i++) {
      final dx = _padding + chartWidth * (i / (points.length - 1));
      final dy = _padding + chartHeight * (1 - (points[i] - minValue) / valueRange);
      canvas.drawCircle(Offset(dx, dy), 4, dotPaint);
    }
  }

  @override
  bool shouldRepaint(covariant _LineChartPainter oldDelegate) {
    return oldDelegate.points != points;
  }
}
```

### 示例分析

- 使用 `valueRange` 避免当最大值与最小值相同时出现除以零。
- `Path.from` + `close` 构造闭合路径，便于填充颜色。
- `shouldRepaint` 根据数据是否变化决定是否重绘，可有效避免不必要的 GPU 开销。

## 性能与最佳实践

- 将复杂绘制逻辑与动画结合时，可以在 `CustomPainter` 中接收 `Animation<double>`，在 `paint` 中根据动画值计算绘制状态。
- 对于不会频繁变化的图形，可启用 `isComplex` 与 `willChange` 提示引擎进行缓存：
  ```dart
  RepaintBoundary(
    child: CustomPaint(
      isComplex: true,
      willChange: false,
      painter: ...,
    ),
  )
  ```
- 当绘制内容需要与命中测试配合时，可以结合 `GestureDetector` 或 `Listener`，通过坐标转换判断点击位置。
