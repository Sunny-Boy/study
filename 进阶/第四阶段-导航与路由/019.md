# 019. 命名路由、参数传递与多页面跳转

命名路由（Named Route）为 Navigator 1.0 提供了更具可维护性的页面管理方式。通过字符串标识符注册页面，开发者可以避免在代码中多处重复创建 Route 对象，并轻松实现参数传递与集中配置。

## 命名路由基础配置

```dart
class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      initialRoute: '/',
      routes: {
        '/': (_) => const HomePage(),
        '/articles': (_) => const ArticleListPage(),
        '/detail': (_) => const DetailPage(),
        '/settings': (_) => const SettingsPage(),
      },
    );
  }
}
```

- `routes` 字典用于注册静态页面。
- `initialRoute` 决定应用启动时展示的页面。
- 导航方式：`Navigator.of(context).pushNamed('/detail');`

## 参数传递方式

### 方式一：`arguments`

```dart
Navigator.of(context).pushNamed(
  '/detail',
  arguments: DetailArguments(id: 42, title: 'Navigator 入门'),
);
```

在目标页面通过 `ModalRoute.of(context)?.settings.arguments` 取值：

```dart
class DetailPage extends StatelessWidget {
  const DetailPage({super.key, this.arguments});

  final DetailArguments? arguments;

  @override
  Widget build(BuildContext context) {
    final args = arguments ??
        ModalRoute.of(context)!.settings.arguments as DetailArguments;

    return Scaffold(
      appBar: AppBar(title: Text(args.title)),
      body: Padding(
        padding: const EdgeInsets.all(24),
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.start,
          children: [
            Text('文章 ID: ${args.id}', style: Theme.of(context).textTheme.titleMedium),
            const SizedBox(height: 16),
            const Text('命名路由支持在任意位置调用 pushNamed / pop 返回上一页。'),
            const SizedBox(height: 24),
            ElevatedButton(
              onPressed: () => Navigator.pop(context, true),
              child: const Text('收藏当前文章并返回'),
            ),
          ],
        ),
      ),
    );
  }
}
```

### 方式二：自定义 `RouteSettings`
当路由由 `onGenerateRoute` 或 `Navigator.push` 手动创建时，可以直接传入 `RouteSettings(name, arguments)`，让路由解析逻辑更加统一。

## 使用 `onGenerateRoute` 实现动态注册

当路由较多或需要运行时决定页面时，可借助 `onGenerateRoute` 动态构建。

```dart
MaterialApp(
  onGenerateRoute: (RouteSettings settings) {
    if (settings.name == '/detail') {
      final args = settings.arguments as DetailArguments;
      return MaterialPageRoute(
        builder: (_) => DetailPage(arguments: args),
        settings: settings,
      );
    }

    if (settings.name == '/profile') {
      final userId = settings.arguments as String;
      return CupertinoPageRoute(
        builder: (_) => ProfilePage(userId: userId),
        settings: settings,
      );
    }

    return MaterialPageRoute(
      builder: (_) => const UnknownPage(),
      settings: settings,
    );
  },
);
```

- `RouteSettings` 保留了路由名称与参数信息，便于日志埋点、深度链接、手势返回等场景。
- 与 `onUnknownRoute` 配合可以为未注册的路由给出兜底页面。

## 多页面跳转示例

下例演示从首页进入列表，再进入详情与设置页面，参数与结果在多级页面之间传递：

```dart
class HomePage extends StatelessWidget {
  const HomePage({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('首页')),
      body: Center(
        child: ElevatedButton(
          onPressed: () => Navigator.pushNamed(context, '/articles'),
          child: const Text('进入文章列表'),
        ),
      ),
    );
  }
}

class ArticleListPage extends StatelessWidget {
  const ArticleListPage({super.key});

  @override
  Widget build(BuildContext context) {
    final articles = List.generate(5, (i) => '文章 $i');

    return Scaffold(
      appBar: AppBar(title: const Text('文章列表')),
      body: ListView.builder(
        itemCount: articles.length,
        itemBuilder: (_, index) => ListTile(
          title: Text(articles[index]),
          onTap: () async {
            final result = await Navigator.pushNamed<bool>(
              context,
              '/detail',
              arguments: DetailArguments(id: index, title: articles[index]),
            );

            if (result == true && context.mounted) {
              ScaffoldMessenger.of(context).showSnackBar(
                SnackBar(content: Text('${articles[index]} 已收藏')),
              );
            }
          },
        ),
      ),
      floatingActionButton: FloatingActionButton(
        onPressed: () => Navigator.pushNamed(context, '/settings'),
        child: const Icon(Icons.settings),
      ),
    );
  }
}

class SettingsPage extends StatelessWidget {
  const SettingsPage({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('设置')),
      body: Center(
        child: ElevatedButton(
          onPressed: () => Navigator.pop(context),
          child: const Text('返回列表'),
        ),
      ),
    );
  }
}

class DetailArguments {
  const DetailArguments({required this.id, required this.title});
  final int id;
  final String title;
}
```

### 多页面导航技巧
1. 使用常量或枚举集中管理路由名称，减少字符串硬编码。
2. 将参数模型定义为不可变类，保持类型安全。
3. 借助 `Navigator.popUntil` 或 `pushNamedAndRemoveUntil` 可以跨越多个页面回退到指定路由，适用于登录成功后清空历史等场景。

## 小结
- 命名路由让导航定义与使用解耦，便于分模块维护。
- `RouteSettings` 是串联导航上下文的纽带：记录名称、参数、深链来源等信息。
- `onGenerateRoute` 提供了一层拦截，可用于权限校验、动态构建页面以及统一动画处理。
