# 027. 显式动画、AnimationController 与 Hero

显式动画（Explicit Animations）给予我们对时间线的完全掌控，适用于复杂交互、分段动画以及与用户手势紧密耦合的场景。本节将从核心类讲起，并提供一个包含多个阶段的综合案例。

## 显式动画的基本结构

显式动画通常包含四个部分：

1. **TickerProvider**：为 `AnimationController` 提供 `Ticker`。常见于 `State` 混入 `SingleTickerProviderStateMixin` 或 `TickerProviderStateMixin`。
2. **AnimationController**：定义动画持续时间、边界值以及控制方法（`forward`、`reverse`、`repeat` 等）。
3. **Tween / Curve**：将 0~1 的进度映射为实际属性值，并控制节奏曲线。
4. **AnimatedWidget / AnimatedBuilder**：在 `Animation` 变化时重建 UI，避免手动调用 `setState`。

```dart
class ScaleControllerDemo extends StatefulWidget {
  const ScaleControllerDemo({super.key});

  @override
  State<ScaleControllerDemo> createState() => _ScaleControllerDemoState();
}

class _ScaleControllerDemoState extends State<ScaleControllerDemo>
    with SingleTickerProviderStateMixin {
  late final AnimationController _controller;
  late final Animation<double> _scale;

  @override
  void initState() {
    super.initState();
    _controller = AnimationController(
      vsync: this,
      duration: const Duration(milliseconds: 300),
    );
    _scale = CurvedAnimation(
      parent: _controller,
      curve: Curves.easeOutBack,
    );
  }

  @override
  void dispose() {
    _controller.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return GestureDetector(
      onTapDown: (_) => _controller.forward(),
      onTapUp: (_) => _controller.reverse(),
      child: ScaleTransition(
        scale: Tween(begin: 1.0, end: 0.9).animate(_scale),
        child: const Icon(Icons.favorite, size: 80, color: Colors.red),
      ),
    );
  }
}
```

## 深入理解 AnimationController

- `AnimationController` 默认输出 0.0~1.0，可通过 `lowerBound`、`upperBound` 调整范围。
- 通过监听 `status` 可以在动画结束后触发后续逻辑，例如链式播放或资源回收。
- 多个动画共享一个 `AnimationController` 时，可以借助 `TweenSequence` 或多个 `Tween` 组合映射不同属性。

## Tween 与补间插值

`Tween<T>` 定义了动画起点与终点，并提供 `lerp` 与 `transform` 方法。常见子类包括 `ColorTween`、`RectTween`、`AlignmentTween` 等。

- 初始值来自 `Tween.begin`
- 终点来自 `Tween.end`
- 中间值通过 `lerp` 按线性比例计算

为了实现非线性节奏，通常会结合 `CurvedAnimation` 或 `Interval`，将单个时间轴拆分为多个片段。

## Hero 动画

`Hero` 小部件用于在页面切换时创建无缝的共享元素过渡：

```dart
Hero(
  tag: 'cover-image',
  child: ClipRRect(
    borderRadius: BorderRadius.circular(12),
    child: Image.network(url),
  ),
)
```

- 两个页面上的 `Hero` 需要使用相同的 `tag`。
- 渲染流程会把源 Hero 从原位置“飞”到目标 Hero 的位置，并在此过程中执行默认或自定义的 `flightShuttleBuilder`。
- 要注意 `Hero` 冲突：同一导航栈上同名 Hero 只能有一个处于激活状态。

## 案例：多阶段显式动画卡片

下面的示例展示了一个包含三个阶段的卡片打开动画：

1. 0%~40%：卡片从缩小状态放大。
2. 40%~80%：卡片提升高度并改变阴影。
3. 80%~100%：内容渐显，按钮滑入。

```dart
class MultiStageCard extends StatefulWidget {
  const MultiStageCard({super.key});

  @override
  State<MultiStageCard> createState() => _MultiStageCardState();
}

class _MultiStageCardState extends State<MultiStageCard>
    with SingleTickerProviderStateMixin {
  late final AnimationController _controller;
  late final Animation<double> _scale;
  late final Animation<double> _elevation;
  late final Animation<double> _opacity;
  late final Animation<Offset> _buttonOffset;

  @override
  void initState() {
    super.initState();
    _controller = AnimationController(
      vsync: this,
      duration: const Duration(milliseconds: 900),
    );

    _scale = TweenSequence<double>([
      TweenSequenceItem(
        tween: Tween(begin: 0.9, end: 1.02).chain(
          CurveTween(curve: Curves.easeOutBack),
        ),
        weight: 40,
      ),
      TweenSequenceItem(
        tween: Tween(begin: 1.02, end: 1.0).chain(
          CurveTween(curve: Curves.easeIn),
        ),
        weight: 10,
      ),
      TweenSequenceItem(
        tween: ConstantTween(1.0),
        weight: 50,
      ),
    ]).animate(_controller);

    _elevation = TweenSequence<double>([
      TweenSequenceItem(
        tween: Tween(begin: 2, end: 12),
        weight: 40,
      ),
      TweenSequenceItem(
        tween: Tween(begin: 12, end: 6),
        weight: 60,
      ),
    ]).animate(CurvedAnimation(
      parent: _controller,
      curve: const Interval(0.25, 0.8, curve: Curves.easeOut),
    ));

    _opacity = CurvedAnimation(
      parent: _controller,
      curve: const Interval(0.8, 1.0, curve: Curves.easeIn),
    );

    _buttonOffset = Tween(begin: const Offset(0, 0.5), end: Offset.zero).animate(
      CurvedAnimation(
        parent: _controller,
        curve: const Interval(0.8, 1.0, curve: Curves.easeOut),
      ),
    );
  }

  @override
  void dispose() {
    _controller.dispose();
    super.dispose();
  }

  void _play() {
    if (_controller.isCompleted) {
      _controller.reverse();
    } else {
      _controller.forward();
    }
  }

  @override
  Widget build(BuildContext context) {
    return Column(
      mainAxisSize: MainAxisSize.min,
      children: [
        ElevatedButton(
          onPressed: _play,
          child: const Text('播放动画'),
        ),
        const SizedBox(height: 24),
        AnimatedBuilder(
          animation: _controller,
          builder: (context, child) {
            return Transform.scale(
              scale: _scale.value,
              child: Material(
                elevation: _elevation.value,
                borderRadius: BorderRadius.circular(24),
                clipBehavior: Clip.antiAlias,
                child: SizedBox(
                  width: 260,
                  height: 320,
                  child: Stack(
                    children: [
                      Positioned.fill(
                        child: Image.network(
                          'https://picsum.photos/400/600?image=1080',
                          fit: BoxFit.cover,
                        ),
                      ),
                      Align(
                        alignment: Alignment.bottomCenter,
                        child: FadeTransition(
                          opacity: _opacity,
                          child: SlideTransition(
                            position: _buttonOffset,
                            child: Padding(
                              padding: const EdgeInsets.all(24),
                              child: ElevatedButton.icon(
                                onPressed: () {},
                                icon: const Icon(Icons.flight),
                                label: const Text('立即预订'),
                              ),
                            ),
                          ),
                        ),
                      ),
                    ],
                  ),
                ),
              ),
            );
          },
        ),
      ],
    );
  }
}
```

### 设计要点

- 使用 `TweenSequence` 可以在单个控制器上组合多个补间段，避免创建额外控制器。
- `Interval` 让不同属性在同一时间轴上错峰播放，便于精细调校节奏。
- `AnimatedBuilder` 减少不必要的 rebuild，只重建依赖动画的局部子树。

通过显式动画，我们可以构建复杂的动效系统，并与手势、滚动、导航等交互模块无缝配合。在下一小节中，我们将把视角转向自定义绘制，继续深入渲染层的能力。
