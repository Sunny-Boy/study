# 041. 项目发布流程与总结

## 1. 项目发布准备

### 1.1 发布前检查清单
- [ ] 完成所有核心功能开发
- [ ] 通过单元测试、集成测试和 UI 测试
- [ ] 修复所有已知 Bug
- [ ] 进行性能优化与内存泄漏检查
- [ ] 完善错误处理与异常捕获
- [ ] 准备应用图标、启动页和宣传素材
- [ ] 编写隐私政策和用户协议
- [ ] 准备应用商店描述和截图

### 1.2 版本管理
```yaml
# pubspec.yaml
name: my_app
description: A comprehensive Flutter application
version: 1.0.0+1  # 版本号+构建号

# 版本命名规范：主版本.次版本.修订号+构建号
# 1.0.0+1: 第一个正式版本，构建号为 1
# 1.1.0+2: 添加新功能，构建号递增
# 1.1.1+3: Bug 修复版本
```

### 1.3 环境配置
```dart
// lib/config/environment.dart
enum Environment { development, staging, production }

class EnvironmentConfig {
  static Environment current = Environment.production;
  
  static String get apiBaseUrl {
    switch (current) {
      case Environment.development:
        return 'https://dev-api.example.com';
      case Environment.staging:
        return 'https://staging-api.example.com';
      case Environment.production:
        return 'https://api.example.com';
    }
  }

  static bool get enableLogging {
    return current != Environment.production;
  }
}
```

## 2. Android 打包与签名

### 2.1 生成密钥库
```bash
# 使用 keytool 生成签名密钥
keytool -genkey -v -keystore ~/key.jks \
  -keyalg RSA -keysize 2048 -validity 10000 \
  -alias my-key-alias

# 输入密钥库密码、密钥密码及相关信息
# 建议密码强度高且妥善保管
```

### 2.2 配置签名信息
```properties
# android/key.properties
storePassword=your_store_password
keyPassword=your_key_password
keyAlias=my-key-alias
storeFile=/path/to/your/key.jks
```

```gradle
// android/app/build.gradle
def keystoreProperties = new Properties()
def keystorePropertiesFile = rootProject.file('key.properties')
if (keystorePropertiesFile.exists()) {
    keystoreProperties.load(new FileInputStream(keystorePropertiesFile))
}

android {
    ...
    signingConfigs {
        release {
            keyAlias keystoreProperties['keyAlias']
            keyPassword keystoreProperties['keyPassword']
            storeFile keystoreProperties['storeFile'] ? file(keystoreProperties['storeFile']) : null
            storePassword keystoreProperties['storePassword']
        }
    }
    
    buildTypes {
        release {
            signingConfig signingConfigs.release
            minifyEnabled true
            shrinkResources true
            proguardFiles getDefaultProguardFile('proguard-android-optimize.txt'), 'proguard-rules.pro'
        }
    }
}
```

### 2.4 构建 APK/AAB
```bash
# 构建 APK（通用格式）
flutter build apk --release

# 构建 App Bundle（推荐用于 Google Play）
flutter build appbundle --release

# 构建分平台 APK（减小包体积）
flutter build apk --split-per-abi --release

# 输出文件位置
# APK: build/app/outputs/flutter-apk/app-release.apk
# AAB: build/app/outputs/bundle/release/app-release.aab
```

## 3. iOS 打包与签名

### 3.1 配置签名证书
1. 在 Apple Developer 账户创建 App ID
2. 创建 Provisioning Profile
3. 在 Xcode 中配置签名：
   - 打开 `ios/Runner.xcworkspace`
   - 选择 Runner 目标
   - 在 Signing & Capabilities 中配置 Team 和证书

### 3.2 配置应用信息
```xml
<!-- ios/Runner/Info.plist -->
<dict>
    <key>CFBundleDisplayName</key>
    <string>My App</string>
    
    <key>CFBundleIdentifier</key>
    <string>com.example.myapp</string>
    
    <key>CFBundleVersion</key>
    <string>1</string>
    
    <key>CFBundleShortVersionString</key>
    <string>1.0.0</string>
    
    <!-- 添加必要的权限说明 -->
    <key>NSPhotoLibraryUsageDescription</key>
    <string>需要访问相册以选择图片</string>
    
    <key>NSCameraUsageDescription</key>
    <string>需要使用相机拍摄照片</string>
</dict>
```

### 3.3 构建 IPA
```bash
# 方式一：使用命令行构建

# 1. 在 Xcode 中打开项目

# 方式三：使用 Fastlane 自动化
```

## 4. 应用商店发布

### 4.1 Google Play 发布流程

#### 4.1.1 创建应用
1. 访问 [Google Play Console](https://play.google.com/console)
2. 创建新应用，填写基本信息
3. 完成商店详情（标题、描述、截图等）

#### 4.1.2 商店详情规范
```
应用标题：不超过 30 字符
简短说明：不超过 80 字符
完整说明：不超过 4000 字符

必需素材：
- 应用图标：512x512 PNG
- 功能图形：1024x500 JPG/PNG
- 手机截图：至少 2 张（推荐 4-8 张）
- 7 英寸平板截图：可选
- 10 英寸平板截图：可选
```

#### 4.1.3 上传应用包
```bash
# 上传 AAB 文件
# 在 Play Console 中：
# 1. 选择应用
# 2. 发布 > 生产版本 > 创建新版本
# 3. 上传 app-release.aab
# 4. 填写版本说明
# 5. 审核并发布
```

#### 4.1.4 内容分级与定价
```yaml
内容分级：
  - 完成内容分级问卷
  - 获取官方分级（如 ESRB、PEGI 等）

定价与分发：
  - 选择免费或付费
  - 选择分发国家/地区
  - 设置本地化定价
```

### 4.2 Apple App Store 发布流程

#### 4.2.1 App Store Connect 配置
1. 访问 [App Store Connect](https://appstoreconnect.apple.com)
2. 创建新 App
3. 填写应用信息：
   - Bundle ID
   - SKU
   - 用户访问权限

#### 4.2.2 应用信息填写
```
必需信息：
- 名称：不超过 30 字符
- 副标题：不超过 30 字符
- 宣传文本：170 字符
- 描述：4000 字符
- 关键词：100 字符（用逗号分隔）
- 技术支持 URL
- 营销 URL（可选）

必需素材：
- App 图标：1024x1024 PNG
- iPhone 截图（多种尺寸）：
  - 6.5 英寸（iPhone 14 Pro Max）
  - 5.5 英寸（iPhone 8 Plus）
- iPad 截图（可选）
- 预览视频（可选）
```

#### 4.2.3 上传构建版本
```bash
# 方式一：Xcode 上传
# Archive > Distribute App > App Store Connect

# 方式二：使用 Transporter
# 下载 Transporter 应用
# 拖入 IPA 文件并上传

# 方式三：使用 Fastlane
fastlane deliver
```

#### 4.2.4 提交审核
```yaml
审核准备：
  - 选择构建版本
  - 填写版本说明
  - 设置发布方式（自动/手动）
  - 提供测试账号（如需要）
  - 完成出口合规信息
  - 完成广告 ID 使用说明

审核时间：通常 1-3 天
审核通过后：根据设置自动或手动发布
```

## 6. 应用更新策略

### 6.1 版本更新检测
```dart
// lib/services/update_service.dart
import 'package:package_info_plus/package_info_plus.dart';
import 'package:version/version.dart';

class UpdateService {
  Future<bool> checkForUpdate() async {
    final PackageInfo packageInfo = await PackageInfo.fromPlatform();
    final currentVersion = Version.parse(packageInfo.version);

    // 从服务器获取最新版本
    final latestVersion = await _fetchLatestVersion();

    return latestVersion > currentVersion;
  }

  Future<Version> _fetchLatestVersion() async {
    // 从 API 获取最新版本号
    final response = await dio.get('/api/version');
    return Version.parse(response.data['version']);
  }

  Future<void> showUpdateDialog(BuildContext context) async {
    final hasUpdate = await checkForUpdate();
    
    if (hasUpdate) {
      showDialog(
        context: context,
        builder: (context) => AlertDialog(
          title: const Text('发现新版本'),
          content: const Text('是否立即更新？'),
          actions: [
            TextButton(
              onPressed: () => Navigator.pop(context),
              child: const Text('稍后'),
            ),
            ElevatedButton(
              onPressed: () => _openStore(),
              child: const Text('立即更新'),
            ),
          ],
        ),
      );
    }
  }

  void _openStore() {
    // 跳转到应用商店
    // Android: 使用 market:// 或 https://play.google.com/store/apps/details?id=
    // iOS: 使用 itms-apps:// 或 https://apps.apple.com/app/
  }
}
```

### 9.1 打包问题
```bash
# 问题：Android 构建失败
# 解决：清理构建缓存
flutter clean
flutter pub get
flutter build apk --release

# 问题：iOS 签名错误
# 解决：检查证书和 Provisioning Profile
# 1. 在 Xcode 中重新配置签名
# 2. 更新过期的证书
# 3. 确保 Bundle ID 匹配
```

### 9.2 性能问题
```dart
// 问题：列表滚动卡顿
// 解决：使用 ListView.builder + const 构造
ListView.builder(
  itemCount: items.length,
  itemBuilder: (context, index) {
    return const ItemWidget(key: ValueKey(index));
  },
)

// 问题：图片加载慢
// 解决：使用缓存和占位符
CachedNetworkImage(
  imageUrl: url,
  memCacheWidth: 800,
  placeholder: (context, url) => const CircularProgressIndicator(),
)
```

### 9.3 兼容性问题
```yaml
# 问题：第三方包版本冲突

  package_name: ^1.0.0

# 解决：使用 Platform.isAndroid/isIOS 条件处理
if (Platform.isAndroid) {
  // Android 特定代码
} else if (Platform.isIOS) {
  // iOS 特定代码
}
```
